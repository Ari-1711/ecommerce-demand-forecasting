# Raw Data Directory

Folder ini digunakan untuk menyimpan dataset mentah (*unprocessed data*).

## Sumber Dataset
Dataset yang digunakan dalam proyek ini adalah **E-Commerce Data** dari Kaggle:
- **URL Dataset:** [Kaggle - E-Commerce Data](https://www.kaggle.com/datasets/carrie1/ecommerce-data)
- **Nama File:** `data.csv` (atau `data.csv.zip`)

## Cara Mengunduh
1. Unduh file `data.csv` dari tautan Kaggle di atas.
2. Simpan file hasil unduhan ke dalam folder `data/raw/` ini sebelum menjalankan pemrosesan lokal.

> *Catatan: File dataset mentah sengaja tidak diunggah ke repositori Git untuk menjaga efisiensi ukuran repositori.*
